## Story

**As a** agente IA,
**I want** enviar mensagens de resposta ao cliente pelo WhatsApp,
**so that** possa completar o ciclo de comunicação.

## Acceptance Criteria

1. Função `sendTextMessage(to, text)` implementada usando Meta Cloud API
2. Suporte a mensagens de texto simples
3. Tratamento de erros de envio (retry com backoff)
4. Log de cada mensagem enviada (timestamp, destinatário, preview)

## Tasks / Subtasks

- [ ] Task 1: Criar WhatsAppSender (AC: 1, 2)
  - [ ] Criar `src/services/whatsapp.sender.ts`
  - [ ] Método `sendTextMessage(to, text)` → POST `/{PHONE_NUMBER_ID}/messages`
  - [ ] Headers: `Authorization: Bearer {META_ACCESS_TOKEN}`, `Content-Type: application/json`
  - [ ] Body: `{ messaging_product: "whatsapp", to, type: "text", text: { body } }`
  - [ ] Método `markAsRead(messageId)` → POST `/{PHONE_NUMBER_ID}/messages` com status "read"
- [ ] Task 2: Tratamento de erros (AC: 3)
  - [ ] Retry com backoff (1s, 2s, 4s — max 3 tentativas)
  - [ ] Timeout de 10s
  - [ ] Logar erro sem reenviar fallback (evitar loop)
- [ ] Task 3: Logging (AC: 4)
  - [ ] Logar cada envio: `{ to: phone (últimos 4 dígitos), textLength, timestamp }`
  - [ ] NUNCA logar conteúdo completo da mensagem (PII/privacidade)
- [ ] Task 4: Testes unitários
  - [ ] Mockar fetch/HTTP client
  - [ ] Testar construção do body
  - [ ] Testar retry em caso de erro

## Dev Notes

### Meta Send Message API
```
POST https://graph.facebook.com/v21.0/{PHONE_NUMBER_ID}/messages

Headers:
  Authorization: Bearer {META_ACCESS_TOKEN}
  Content-Type: application/json

Body:
{
  "messaging_product": "whatsapp",
  "to": "5512991650505",
  "type": "text",
  "text": { "body": "Olá! Como posso ajudar? 😊" }
}
```

### Mark as Read
```json
{
  "messaging_product": "whatsapp",
  "status": "read",
  "message_id": "wamid.xxx"
}
```

### Variáveis de Ambiente
- `META_ACCESS_TOKEN` — Bearer token do System User
- `META_PHONE_NUMBER_ID` — ID interno do número WhatsApp

### Testing
- **Framework:** Vitest
- Mockar `fetch` global
- Testar construção do request body
- Testar retry logic com erros simulados
