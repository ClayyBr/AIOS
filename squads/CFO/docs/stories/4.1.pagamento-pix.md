## Story

**As a** cliente,
**I want** receber a chave Pix para pagamento e poder enviar meu comprovante,
**so that** possa pagar meu pedido de forma rápida e prática.

## Acceptance Criteria

1. Chave Pix pré-configurada em variáveis de ambiente (chave + nome do recebedor)
2. Quando cliente escolhe Pix, agente envia: chave copia-e-cola + nome do recebedor + valor total
3. Agente solicita envio do comprovante após pagamento
4. Quando cliente envia imagem/documento, agente registra recebimento e confirma o pedido
5. Status do pedido atualizado na planilha

## Tasks / Subtasks

- [ ] Task 1: Enviar dados Pix (AC: 1, 2, 3)
  - [ ] Ler `PIX_KEY` e `PIX_RECEIVER_NAME` do env
  - [ ] Formatar mensagem Pix:
    ```
    💰 *Pagamento via Pix*
    
    Chave Pix (copia e cola):
    `email@restaurante.com`
    
    Nome: Restaurante XYZ
    Valor: R$ 49,00
    
    Após o pagamento, envie o comprovante aqui 📸
    ```
  - [ ] Atualizar estado da sessão para `AWAITING_PIX_PROOF`
- [ ] Task 2: Detectar comprovante (AC: 4)
  - [ ] No `MessageController`, detectar mensagens do tipo `image` ou `document`
  - [ ] Se sessão está em `AWAITING_PIX_PROOF` e recebeu imagem → considerar como comprovante
  - [ ] Responder: "✅ Comprovante recebido! Pedido confirmado. Já está sendo preparado 🍽️"
- [ ] Task 3: Atualizar status na planilha (AC: 5)
  - [ ] Registrar pedido com `paymentMethod: "Pix"` e `paymentDetails: "Comprovante recebido"`
- [ ] Task 4: Testes unitários
  - [ ] Testar formatação da mensagem Pix
  - [ ] Testar transição de estado: AWAITING_PAYMENT → AWAITING_PIX_PROOF → CONFIRMED

## Dev Notes

### Variáveis de Ambiente
- `PIX_KEY` — Chave Pix do restaurante (email, CPF, telefone ou aleatória)
- `PIX_RECEIVER_NAME` — Nome que aparece na transferência

### Detecção de Tipo de Mensagem
O webhook da Meta inclui `type: "image"` ou `type: "document"` para arquivos enviados.
Não fazemos verificação automática do comprovante (é manual pelo Cleison no app do banco).

### Testing
- **Framework:** Vitest
- Testar formatação da mensagem Pix com diferentes valores
- Testar state machine: AWAITING_PAYMENT → AWAITING_PIX_PROOF → CONFIRMED
