# Story 2.1: Agente Financeiro — CFO Squad

## Status

**Done**

## Story

**As a** dono de restaurante,
**I want** um agente financeiro especializado em contabilidade gerencial, DRE, relatórios, projeções e análise macro,
**so that** eu tenha um CFO virtual que me dê visão completa da saúde financeira do negócio, separado do agente de custos operacionais.

### Regras do Projeto (NÃO NEGOCIÁVEIS)

1. **Formato AIOS:** Todos os agents usam YAML frontmatter + markdown body
2. **Idioma:** pt-BR em todo conteúdo
3. **Imports absolutos:** Os paths em `dependencies` são relativos ao diretório do squad
4. **Sem invenção:** Usar apenas dados e fórmulas do Manual de Contabilidade como referência
5. **Sem deleção:** Nenhum arquivo existente deve ser deletado, apenas modificado
6. **Consistência:** O agente financeiro deve seguir o mesmo padrão estrutural dos agents existentes (`arquiteto-lucro.md`, `controlador-estoque.md`)
