# Checklist de Fechamento Mensal

Executar todos os itens abaixo até o **dia 7 do mês seguinte**.

## Inventário (Último Dia Útil do Mês)
- [ ] Realizar inventário físico completo (porta fechada, sem movimentação)
- [ ] Pesar e contar todos os itens de estoque
- [ ] Registrar quantidades e valores unitários atualizados
- [ ] Separar: alimentos perecíveis, secos, bebidas, descartáveis, limpeza
- [ ] Descartar itens vencidos e registrar como perda

## Compras (Dia 1-3)
- [ ] Consolidar todas as notas fiscais de compra do mês
- [ ] Verificar se há notas pendentes (compras recebidas sem NF)
- [ ] Somar total de compras por categoria (alimentos, bebidas, descartáveis, limpeza)
- [ ] Identificar compras fora do padrão (preços muito acima do normal)

## Vendas (Dia 1-3)
- [ ] Extrair relatório de vendas do PDV/Saipos
- [ ] Separar: vendas de alimentos (salão), bebidas, delivery
- [ ] Verificar cancelamentos e devoluções
- [ ] Conferir recebimentos de cartão vs vendas (conciliação)
- [ ] Registrar vendas em dinheiro (se houver)

## CMV (Dia 3-5)
- [ ] Calcular: CMV = Estoque Inicial + Compras - Estoque Final
- [ ] Calcular CMV % de alimentos: CMV Alimentos ÷ Vendas Alimentos
- [ ] Calcular CMV % de bebidas: CMV Bebidas ÷ Vendas Bebidas
- [ ] Comparar com CMV meta (32%)
- [ ] Se variação > 2%: investigar causa (usar task *cmv)

## Mão de Obra (Dia 3-5)
- [ ] Fechar folha de pagamento
- [ ] Calcular encargos (FGTS, férias provisão, 13º provisão)
- [ ] Registrar pró-labore dos sócios
- [ ] Contabilizar extras e diaristas
- [ ] Somar VT e VA distribuídos

## Custos Fixos (Dia 5-7)
- [ ] Registrar aluguel, condomínio, IPTU
- [ ] Registrar contas: energia, água, gás, internet, telefone
- [ ] Registrar seguros, desinsetização, lavanderia
- [ ] Registrar material de limpeza e descartáveis
- [ ] Registrar contabilidade, sistemas, marketing

## DRE (Dia 5-7)
- [ ] Montar DRE gerencial completo (usar task *dre)
- [ ] Calcular todos os KPIs: CMV%, MO%, Prime Cost%, Lucro%
- [ ] Comparar com mês anterior
- [ ] Identificar as 3 principais variações

## Análise e Ações (Dia 7-10)
- [ ] Listar os 3 principais insights do mês
- [ ] Definir 3 ações corretivas para o próximo mês
- [ ] Gerar relatório para sócios (usar task *relatorio)
- [ ] Salvar insights na memória do agente
- [ ] Atualizar fichas técnicas se houver variação de preço > 5%
