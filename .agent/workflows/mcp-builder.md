# 🔌 MCP Builder

Construir servidores MCP seguindo o padrão Model Context Protocol.

## Fluxo

1. Leia o guia completo: `.claude/skills/mcp-builder/SKILL.md`
2. Entenda os requisitos do MCP server desejado
3. Siga as instruções passo a passo do SKILL.md para:
   - Scaffold da estrutura do projeto
   - Implementação dos tools/resources
   - Configuração do transport (stdio/SSE)
   - Testes e validação
4. Registrar o MCP no Docker MCP Toolkit (se disponível)
