## Story

**As a** cliente,
**I want** poder falar com um atendente humano quando a IA não conseguir me ajudar,
**so that** possa resolver situações complexas ou reclamações.

## Acceptance Criteria

1. Agente detecta gatilhos de handoff: pedido explícito ("falar com humano"), reclamação, ou pergunta fora do contexto
2. Agente envia mensagem educada: "Vou te transferir para nosso atendimento pessoal. Aguarde um momento 😊"
3. Bot pausa **apenas para o número do cliente** que solicitou handoff
4. Lista de números em handoff armazenada em memória (não processa mensagens desses números)
5. Mecanismo para reativar o bot para um número (manual via endpoint ou timeout configurável)

## Tasks / Subtasks

- [ ] Task 1: Detecção de handoff (AC: 1)
  - [ ] Incluir instruções no system prompt do Gemini:
    - Se cliente pedir humano → responder com tag `[HANDOFF]`
    - Se cliente reclamar/estiver insatisfeito → responder com tag `[HANDOFF]`
    - Se cliente perguntar algo fora do contexto → responder com tag `[HANDOFF]`
  - [ ] No `MessageController`, detectar tag `[HANDOFF]` na resposta do Gemini
- [ ] Task 2: Executar handoff (AC: 2, 3, 4)
  - [ ] Enviar mensagem educada (AC: 2)
  - [ ] Chamar `SessionManager.setHandoff(phoneNumber, true)` (AC: 3)
  - [ ] No início do `handleIncomingMessage()`, verificar `isHandoff(phone)` → se true, ignorar mensagem (AC: 4)
- [ ] Task 3: Reativação do bot (AC: 5)
  - [ ] Criar endpoint `POST /admin/reactivate` com body `{ phone: "5512..." }`
  - [ ] Chamar `SessionManager.setHandoff(phoneNumber, false)` e resetar sessão
  - [ ] Alternativa: timeout de handoff configurável (ex: 2 horas)
- [ ] Task 4: Testes unitários
  - [ ] Testar detecção de `[HANDOFF]` na resposta
  - [ ] Testar que mensagens de número em handoff são ignoradas
  - [ ] Testar reativação

## Dev Notes

### System Prompt — Instruções de Handoff
```
REGRAS DE HANDOFF:
- Se o cliente pedir para falar com um humano, atendente real, ou gerente: inclua [HANDOFF] na sua resposta
- Se o cliente reclamar de algo (pedido errado, demora excessiva, insatisfação): inclua [HANDOFF]
- Se o cliente perguntar algo que você não sabe ou que não é sobre o restaurante: inclua [HANDOFF]
- A tag [HANDOFF] deve estar na última linha da resposta, APÓS a mensagem de despedida
```

### Endpoint Admin (Protegido)
```
POST /admin/reactivate
Headers: X-Admin-Key: {ADMIN_SECRET}
Body: { "phone": "5512991650505" }
Response: { "success": true, "message": "Bot reativado para 5512991650505" }
```

### Testing

- Testar `isHandoff()` retorna true após `setHandoff(phone, true)`
- Testar que mensagens de números em handoff não são processadas
- Testar reativação via método direto
