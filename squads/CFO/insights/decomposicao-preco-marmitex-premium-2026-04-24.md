## 6. O QUE ACONTECE QUANDO CMV SOBE DE 23% PARA 35%?

A diferença é de **R$ 3,05 por unidade** (R$ 9,07 − R$ 6,02).

Isso pode acontecer por:

| Causa | Impacto |
|---|---|
| Proteína mais cara (ex: bisteca vs frango) | CMV sobe +R$ 1,50 – 3,00/un |
| Porção maior (ex: 200g proteína → 280g) | CMV sobe proporcionalmente |
| Desperdício elevado na cozinha | CMV global sobe sem controle |
| Sazonalidade (frango sobe no verão) | CMV sobe temporariamente |
| Novo prato com ingredientes premium | CMV unitário mais alto |

> 💡 **Insight do Gerente:** O CMV de 35% não é uma meta — é um **teto de segurança**. Operar em 35% com a embalagem premium de R$ 2,00 exige volume alto para que os fixos sejam cobertos. Seu CMV atual de 23,2% é sua maior vantagem competitiva. Cada ponto percentual abaixo de 35% vale **R$ 0,26/unidade de lucro adicional**.

## 7. QUAL SERIA O PREÇO IDEAL COM CMV 35% E TODOS OS BENCHMARKS CORRETOS?

Para que **todos** os indicadores fiquem na média Abrasel **com margem confortável nos fixos (14%)**, o preço correto seria:

```
Custo total a distribuir:
  CMV 35%:         R$ X × 35%  = ingredientes
  MO 27%:          R$ X × 27%  = mão de obra
  Embalagem:       R$ 2,00     = fixo
  Fixos 14%:       R$ X × 14%  = estrutura
  Impostos 6%:     R$ X × 6%   = governo
  Taxas 2,5%:      R$ X × 2,5% = pagamento
  Marketing 2%:    R$ X × 2%   = captação
  Lucro 12%:       R$ X × 12%  = resultado

Custo fixo (embalagem R$2,00) obriga:
  R$ 2,00 = 7,7% × X  →  X = R$ 2,00 / 0,077 = R$ 25,97  (preço mínimo para embalagem não pesar mais que 7,7%)

Calculando para fixos = 14% com todos os demais:
  (35 + 27 + 14 + 6 + 2,5 + 2 + 12) = 98,5% variáveis
  Restam 1,5% → embalagem precisaria ser só 1,5%
  Mas embalagem é FIXA em R$ 2,00...

Solução: Preço onde R$2,00 = diferença entre 100% e 98,5%:
  R$ 2,00 / 0,015 = R$ 133,33 → inviável

Abordagem correta (resolvendo para X com embalagem embutida):
  Total variáveis sem embalagem = 98,5%
  Custo total = 98,5% × X + R$ 2,00 = X
  X − 0,985X = 2,00
  0,015X = 2,00
  X = R$ 133,33 → não faz sentido para marmitex
```

> 🎯 **Conclusão aritmética:** A embalagem premium de R$ 2,00 é um **custo fixo por unidade** que, quando o CMV também sobe para 35%, comprime os custos fixos operacionais para um nível insustentável em volumes baixos. A embalagem premium só é viável com CMV **abaixo de 30%** — que é exatamente a sua situação atual (23,2%).
