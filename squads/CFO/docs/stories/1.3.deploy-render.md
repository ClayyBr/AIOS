## Story

**As a** operador,
**I want** o servidor deployado no Render com variáveis de ambiente configuradas,
**so that** o webhook esteja acessível publicamente 24/7.

## Acceptance Criteria

1. `Dockerfile` ou `render.yaml` configurado para deploy
2. Variáveis de ambiente documentadas: `META_VERIFY_TOKEN`, `META_ACCESS_TOKEN`, `META_PHONE_NUMBER_ID`, `GEMINI_API_KEY`, `GOOGLE_SHEETS_CREDENTIALS`
3. Health check do Render configurado no endpoint `/health`
4. Servidor respondendo publicamente em URL HTTPS do Render
5. README com instruções de deploy

## Tasks / Subtasks

- [ ] Task 1: Criar configuração de deploy (AC: 1)
  - [ ] Criar `render.yaml` com Web Service config (build command, start command, env vars)
  - [ ] Alternativa: Criar `Dockerfile` multi-stage (builder + runner)
- [ ] Task 2: Documentar variáveis de ambiente (AC: 2)
  - [ ] Atualizar `.env.example` com todas as variáveis necessárias
  - [ ] Documentar como obter cada credencial
- [ ] Task 3: Configurar health check (AC: 3)
  - [ ] Garantir que `GET /health` retorna 200 OK com body JSON
  - [ ] No `render.yaml`, configurar `healthCheckPath: /health`
- [ ] Task 4: Criar README completo (AC: 5)
  - [ ] Instruções de setup local
  - [ ] Instruções de deploy no Render
  - [ ] Lista de variáveis de ambiente com descrição
  - [ ] Troubleshooting comum

## Dev Notes

### render.yaml Exemplo
```yaml
services:
  - type: web
    name: atendente-whatsapp
    runtime: node
    buildCommand: npm install && npm run build
    startCommand: npm start
    healthCheckPath: /health
    envVars:
      - key: NODE_ENV
        value: production
      - key: META_VERIFY_TOKEN
        sync: false
      - key: META_ACCESS_TOKEN
        sync: false
      - key: META_PHONE_NUMBER_ID
        sync: false
      - key: META_APP_SECRET
        sync: false
      - key: GEMINI_API_KEY
        sync: false
      - key: GOOGLE_SHEETS_CREDENTIALS
        sync: false
      - key: SHEETS_CARDAPIO_ID
        sync: false
      - key: PIX_KEY
        sync: false
      - key: PIX_RECEIVER_NAME
        sync: false
```

### Dockerfile Alternativo
```dockerfile
FROM node:20-slim AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-slim AS runner
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./
EXPOSE 3000
CMD ["node", "dist/server.js"]
```

### Testing
- **Manual:** Verificar que o servidor responde no URL público do Render
- **Health Check:** `curl https://<URL_RENDER>/health` retorna `{ "status": "ok" }`
