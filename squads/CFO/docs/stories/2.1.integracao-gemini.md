## Story

**As a** agente IA,
**I want** processar mensagens dos clientes usando Gemini 1.5 Flash,
**so that** possa gerar respostas inteligentes e contextuais.

## Acceptance Criteria

1. SDK `@google/generative-ai` configurado com a API Key do Google AI Studio
2. System prompt definido com persona de atendente humanizada (pt-BR, tom simpático)
3. Temperature configurada em 0.3 (respostas previsíveis)
4. Safety settings configurados para contexto de restaurante
5. Tratamento de erros da API (rate limit, timeout, falha) com fallback message ao cliente

## Tasks / Subtasks

- [ ] Task 1: Criar GeminiService (AC: 1, 3, 4)
  - [ ] Criar `src/services/gemini.service.ts`
  - [ ] Inicializar `GoogleGenerativeAI` com API Key do env
  - [ ] Configurar model `gemini-1.5-flash` com temperature 0.3
  - [ ] Configurar safety settings: `BLOCK_NONE` para HARASSMENT e SEXUALLY_EXPLICIT (evitar bloqueios falsos com nomes de comida)
  - [ ] Criar método `generateResponse(systemPrompt, messageHistory, userMessage)` → string
- [ ] Task 2: Criar system prompt da persona (AC: 2)
  - [ ] Criar `src/prompts/atendente.prompt.ts`
  - [ ] Definir persona: nome "Luna", tom simpático, uso de emojis, conhecedora do cardápio
  - [ ] Incluir regras: só falar sobre o restaurante, não inventar itens, ser educada
  - [ ] Template dinâmico: aceita dados do cardápio e promoções como parâmetro

- [ ] Task 4: Testes unitários
  - [ ] Testar construção do system prompt
  - [ ] Testar tratamento de erros com mock do SDK

## Dev Notes

### GeminiService — Estrutura Base
```typescript
import { GoogleGenerativeAI } from '@google/generative-ai';

const genAI = new GoogleGenerativeAI(env.GEMINI_API_KEY);
const model = genAI.getGenerativeModel({
  model: 'gemini-1.5-flash',
  generationConfig: { temperature: 0.3 },
  safetySettings: [
    { category: 'HARM_CATEGORY_HARASSMENT', threshold: 'BLOCK_NONE' },
    { category: 'HARM_CATEGORY_SEXUALLY_EXPLICIT', threshold: 'BLOCK_NONE' },
  ],
});
```

### System Prompt — Diretrizes
- Persona: "Luna" — atendente virtual simpática do restaurante
- Idioma: Português Brasileiro (pt-BR)
- Tom: Humanizado, profissional, com emojis moderados
- Regras: NÃO inventar itens, NÃO falar sobre assuntos fora do restaurante, NÃO dar conselhos médicos/nutricionais

### Testing
- **Framework:** Vitest
- Mockar `@google/generative-ai` SDK
- Testar construção do prompt com diferentes dados de cardápio
- Testar retry logic
