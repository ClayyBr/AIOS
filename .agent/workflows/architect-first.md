# 🏗️ Architect First

Workflow que prioriza arquitetura antes de implementação.

## Fluxo

1. Leia o guia completo: `.claude/skills/architect-first/SKILL.md`
2. Execute o fluxo de arquitetura-primeiro:
   - Análise de requisitos e restrições
   - Design de arquitetura high-level
   - Definição de tech stack
   - Planejamento de API/integrações
   - Documentação de decisões
3. Somente após aprovação da arquitetura, iniciar implementação
