# Story 3.3: Dashboard de Vendas (Monitoramento Estratégico)

**Status:** Done
**Epic:** 3 - Marketing e Vendas Inteligente
**Author:** @pm (Morgan)

## Story
**As a** Gerente Geral e Dono do Restaurante,
**I want** um comando `*vendas-dashboard` que mostre a performance das campanhas e do estoque salvo (PVPS),
**so that** eu saiba se a estratégia de "raspadinha" e "promoção de validade" está realmente dando lucro.

## Acceptance Criteria
1.  **Visão Consolidada (KPIs):**
    *   **Receita Gerada:** Total vendido através de campanhas.
    *   **Investimento (CMV Brindes):** Custo total dos brindes ou descontos.
    *   **ROI (%):** Retorno sobre Investimento.
    *   **Estoque Salvo (PVPS):** Valor (R$) que seria perdido se não fosse vendido.

2.  **Output Dual-Format:**
    *   O comando deve gerar um resumo rápido no terminal (`.md`) E um dashboard visual detalhado em `.html` com gráficos (via Mermaid ou CSS simples).

3.  **Histórico:**
    *   Deve ler o arquivo `squads/CFO/data/campanhas-ativas.json` para calcular os totais.

4.  **Integração:**
    *   O `@gerente-geral` deve ser capaz de invocar este dashboard dentro do seu relatório mensal.
