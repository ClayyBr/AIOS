# Story 3.1: Chef de Imagem — Agente Gerador de Fotos de Pratos (CFO Squad)

## Status

**InProgress**

## Story

**As a** dono de restaurante,
**I want** um agente de IA que gere fotos profissionais dos meus pratos a partir de descrições simples e imagens de referência,
**so that** eu tenha assets visuais consistentes e de alta qualidade para cardápios e marketing sem depender de fotógrafo profissional.

---

## Acceptance Criteria

### Epic 1 — Agente + MCP Server

1. Arquivo `agents/chef-imagem.md` criado com system prompt completo no formato AIOS (YAML frontmatter + markdown body)
2. O agente declara dependência na task: `gerar-foto-prato.md`
3. System prompt define: persona (Food Photographer & Prompt Engineer), princípios de fotografia culinária, regras de enriquecimento de prompt, comandos, formato de resposta
4. Campo `whenToUse` descreve claramente quando usar `@chef-imagem` vs outros agentes
5. Nova task `tasks/gerar-foto-prato.md` criada (input: texto do prato + referência opcional + negative prompt opcional → output: imagem salva)
6. Pasta `design/` criada no diretório do squad para armazenamento das imagens geradas
7. MCP Server criado em `packages/mcp-chef-imagem/` (Node.js) com tool `gerar_imagem_prato`
8. MCP Server usa API Key do Google AI Studio (variável de ambiente `GOOGLE_AI_STUDIO_API_KEY`)
9. Tool `gerar_imagem_prato` aceita: `prompt` (string), `imagem_referencia` (base64, opcional), `negative_prompt` (string, opcional)
10. Tool salva imagem gerada em `squads/CFO/design/` com nome descritivo auto-gerado
11. Tool retorna ao agente: path do arquivo salvo, prompt final usado, timestamp
12. `squad.yaml` atualizado: `chef-imagem.md` em agents, `gerar-foto-prato.md` em tasks
13. `agents/gerente-geral.md` atualizado: `dependencies.agents` inclui `chef-imagem.md`, lista de agentes inclui `📸 @chef-imagem`
14. Configuração MCP registrada no arquivo de ambiente (`.mcp.json` ou equivalente)
15. Nenhum arquivo existente deletado — apenas adicionados ou modificados
