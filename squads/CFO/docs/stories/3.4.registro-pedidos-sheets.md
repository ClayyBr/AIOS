## Story

**As a** gerente,
**I want** que todos os pedidos sejam registrados automaticamente no Google Sheets,
**so that** possa acompanhar e gerenciar a operação.

## Acceptance Criteria

1. Função `registrarPedido(pedido)` que insere nova linha na planilha de pedidos
2. Colunas: nº pedido, data/hora, nome cliente, telefone, endereço, itens (texto), valor total, forma pagamento, status, origem (site/whatsapp)
3. Número do pedido gerado sequencialmente (leitura do último nº + 1)
4. Status inicial: "Em Preparo"

## Tasks / Subtasks

- [ ] Task 1: Implementar registro de pedidos (AC: 1, 2, 4)
  - [ ] Adicionar método `registrarPedido(order: Order)` no `SheetsService`
  - [ ] Usar `sheets.spreadsheets.values.append()` para adicionar nova linha
  - [ ] Mapear `Order` para array de colunas na ordem correta
  - [ ] Status inicial: "Em Preparo"
  - [ ] Data/hora formatada: `DD/MM/YYYY HH:mm`

### Append API
```typescript
await sheets.spreadsheets.values.append({
  spreadsheetId: env.SHEETS_PEDIDOS_ID,
  range: 'Pedidos!A:L',
  valueInputOption: 'USER_ENTERED',
  requestBody: {
    values: [[orderNumber, dateTime, name, phone, address, items, subtotal, delivery, total, payment, 'Em Preparo', source]]
  }
});
```
