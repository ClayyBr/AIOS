# Checklist de Pré-Abertura Financeira

Completar todos os itens antes da inauguração do restaurante.

## Cardápio e Fichas Técnicas (8 semanas antes)
- [ ] Definir cardápio do buffet (categorias e preparações)
- [ ] Definir cardápio de pratos executivos (5-7 opções) — *3 pratos base criados*
- [ ] Definir cardápio de delivery (quais pratos, embalagens)
- [x] Criar ficha técnica: Strogonoff de Frango (`fichas/strogonoff-frango.md`)
- [x] Criar ficha técnica: Frango a Parmegiana (`fichas/frango-parmegiana.md`)
- [x] Criar ficha técnica: Filé de Frango Grelhado (`fichas/file-frango-grelhado-batata-frita.md`)
- [ ] Criar fichas técnicas dos demais pratos (após definir cardápio)
- [ ] Validar fichas com teste prático (3 repetições)
- [ ] Documentar FC e FCc reais dos ingredientes principais
- [ ] Definir utensílios de porcionamento para cada prato

## Precificação (6 semanas antes)
- [ ] Definir estrutura de custos (% CMV, MO, fixos, impostos, lucro)
- [ ] Validar que a soma = 100%
- [ ] Calcular preço de cada prato executivo (usar task *precificar)
- [ ] Calcular preço do kg do buffet com margem de segurança
- [ ] Definir preços de delivery (incluir embalagem + taxa marketplace)
- [ ] Definir preços de bebidas
- [ ] Comparar com preços da concorrência local
- [ ] Ajustar se necessário (porção, ingrediente ou margem)

## Fornecedores (6 semanas antes)
- [ ] Cotar mínimo 3 fornecedores por categoria de insumo
- [ ] Fazer teste de rendimento (FC) com amostra de cada fornecedor
- [ ] Calcular custo REAL por fornecedor (preço × FC)
- [ ] Escolher fornecedor principal por categoria
- [ ] Identificar fornecedor backup (emergência)
- [ ] Negociar prazos e condições de pagamento
- [ ] Definir frequência de entrega por categoria

## Estoque Inicial (1 semana antes)
- [ ] Calcular par stock para 3-5 dias de operação
- [ ] Fazer lista de primeira compra com quantidades e custos
- [ ] Comprar itens de despensa (longa validade) primeiro
- [ ] Comprar perecíveis 1-2 dias antes da abertura
- [ ] Registrar inventário inicial com preços unitários
- [ ] Organizar estoque por categoria (PVPS — Primeiro que Vence, Primeiro que Sai)

## Ponto de Equilíbrio e Projeções (4 semanas antes)
- [x] Calcular ponto de equilíbrio: **27 pratos/dia = R$ 21.030/mês**
- [x] Projetar faturamento para 3 cenários (`relatorios/dre-projetado-pre-abertura.md`)
- [ ] Verificar se ponto de equilíbrio é viável com a capacidade do restaurante
- [ ] Calcular capital de giro necessário (mínimo 4 meses de custos fixos ≈ R$ 50.040)
- [x] Montar DRE projetado (`relatorios/dre-projetado-pre-abertura.md`)
- [ ] Montar fluxo de caixa projetado para os 3 primeiros meses

## Sistemas e Controles (3 semanas antes)
- [ ] PDV/Caixa registradora configurado e testado
- [ ] Categorias de venda separadas: alimentos salão, bebidas, delivery
- [ ] Planilha de controle de sobras e desperdício pronta
- [ ] Planilha de inventário pronta (ou sistema)
- [ ] Balanças calibradas (cozinha + salão se buffet)
- [x] Squad CFO configurado e funcionando no IDE
  - [x] 3 agentes otimizados (Gerente Geral, CFO, Estoque)
  - [x] 14 tasks operacionais
  - [x] Par stock com 14 insumos base
  - [x] Inventário inicial com 9 itens

## Equipe (2 semanas antes)
- [ ] Equipe treinada em fichas técnicas e porcionamento
- [ ] Responsável pelo inventário definido
- [ ] Responsável pelo recebimento de mercadorias definido
- [ ] Procedimento de recebimento cego configurado (se aplicável)

## Financeiro e Legal (4 semanas antes)
- [ ] Conta bancária PJ aberta e separada da pessoal
- [ ] Regime tributário confirmado com contador (Simples Nacional)
- [ ] CNAE correto para restaurante
- [ ] Alvará de funcionamento
- [ ] Licença da vigilância sanitária
- [ ] Seguro do ponto comercial

## Soft Opening (3 dias antes)
- [ ] Realizar soft opening para amigos/família
- [ ] Medir: tempo de atendimento, sobras, qualidade dos pratos
- [ ] Ajustar volume de produção com base no teste
- [ ] Calibrar porcionamento da equipe
- [ ] Testar PDV em operação real

## Dia 1 — Inauguração
- [ ] Registrar TUDO: vendas, sobras, reclamações, elogios
- [ ] Pesar sobras no final do dia (sobra limpa e resto ingesto)
- [ ] Registrar número de clientes e ticket médio
- [ ] Anotar qualquer imprevisto para ajuste no dia seguinte
- [ ] Celebrar! 🎉
