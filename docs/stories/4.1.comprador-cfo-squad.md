# Story 4.1: Comprador — Agente de Cotação de Preços (CFO Squad)

## Status

**InProgress** — Implementação completa, aguardando QA.

## Story

**As a** dono de restaurante na região do Vale do Paraíba — SP,
**I want** um agente de IA (`@comprador`) que pesquise preços de ingredientes nos sites **públicos** dos principais supermercados atacadistas (Spani, Tenda, Atacadão, Assaí e Fort Atacadista),
**so that** eu receba um arquivo CSV/Excel comparativo de preços sem precisar consultar cada site manualmente.

---

## Contexto

O squad CFO já possui 7 agentes operacionais. O `@comprador` será o **Agente 8**, subordinado ao `@gerente-geral` na hierarquia, porém também invocável diretamente pelo dono via `@comprador` no chat.

## Dev Notes

### Padrão de Referência

| Aspecto | Referência no Projeto |
|---------|----------------------|
| Formato do Agent (.md) | `agents/vendas.md` (YAML frontmatter + commands + integrations) |
| Formato da Task (.md) | `tasks/avaliar-fornecedor.md` (inputs Zod-style + steps) |
| Estrutura MCP Server | `packages/mcp-chef-imagem/` (TypeScript, stdio transport, Zod schemas) |
| Skill de Construção MCP | `Skills Claude/skills/mcp-builder/SKILL.md` (Fases 1-4) |

### Estratégia de Scraping

1. **Abordagem:** HTTP requests (`axios`) + parsing HTML (`cheerio`), sem browser headless
2. **Fallback:** Se algum site bloquear requests diretos, migrar aquele scraper específico para `playwright` headless
3. **Paralelismo:** `Promise.allSettled()` para buscar em todos os mercados simultaneamente (partial success)
4. **Rate limiting:** 1-2 segundos de delay entre requests para o mesmo domínio (evitar bloqueio)
5. **User-Agent:** Configurar um User-Agent realista nos headers HTTP
