## Story

**As a** agente IA,
**I want** detectar e confirmar automaticamente pedidos vindos do site,
**so that** possa agilizar o fluxo de pedidos online.

## Acceptance Criteria

1. Parser que detecta o padrão de comanda formatada (ex: `#### NOVO PEDIDO ####`)
2. Extração de dados da comanda: nº pedido, cliente, telefone, endereço, itens, valores, pagamento
3. Resposta automática confirmando o pedido: "Pedido #XX recebido! Já está sendo preparado 🍽️"
4. Registro do pedido na Google Sheets de pedidos

## Tasks / Subtasks

- [ ] Task 1: Criar detector de comanda (AC: 1)
  - [ ] No `MessageController`, criar método `isComandaSite(text)` → boolean
  - [ ] Detectar padrão: começa com `#### NOVO PEDIDO ####` ou similar
- [ ] Task 2: Criar parser de comanda (AC: 2)
  - [ ] Criar métodos no `OrderService` (`src/services/order.service.ts`)
  - [ ] Método `parseComandaSite(text)` → `Order`
  - [ ] Extrair via regex: nº pedido, nome, telefone, endereço, itens, valores, pagamento
  - [ ] Criar tipos em `src/types/order.types.ts`: `Order`, `OrderItem`
- [ ] Task 3: Resposta de confirmação (AC: 3)
  - [ ] Formatar mensagem: "✅ Pedido #XX recebido! Já está sendo preparado 🍽️\nPrazo estimado: ~50min"
  - [ ] Enviar via `WhatsAppSender.sendTextMessage()`
- [ ] Task 4: Registro na planilha (AC: 4)
  - [ ] Usar `SheetsService.registrarPedido()` (criado na Story 3.4)
  - [ ] Se Story 3.4 ainda não implementada, criar stub/TODO
- [ ] Task 5: Integrar no fluxo principal
  - [ ] No `MessageController.handleIncomingMessage()`: se `isComandaSite()` → fluxo confirmador
- [ ] Task 6: Testes unitários
  - [ ] Testar `isComandaSite()` com comandas reais e mensagens normais
  - [ ] Testar `parseComandaSite()` com exemplos de comanda
  - [ ] Criar fixtures com exemplos reais em `tests/fixtures/comanda-samples.ts`
