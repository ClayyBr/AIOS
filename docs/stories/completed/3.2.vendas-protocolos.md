# Story 3.2: Protocolos de Segurança e Comunicação (Vendas)

**Status:** Done
**Epic:** 3 - Marketing e Vendas Inteligente
**Author:** @pm (Morgan)

## Story
**As a** Dono do Restaurante (e CFO),
**I want** que o agente `@vendas` tenha protocolos rígidos de comunicação com `@financeiro` e `@arquiteto-lucro`,
**so that** não sejam criadas campanhas que deem prejuízo ou que furem o DRE.

## Acceptance Criteria
1.  **Validação de Margem (Gatekeeper):**
    *   O agente `@vendas` **NUNCA** pode sugerir um preço promocional sem antes consultar a Margem de Contribuição atual com o `@arquiteto-lucro`.
    *   Erro Crítico: Se Vendas sugerir venda abaixo do CMV.

2.  **Notificação Fiscal (Audit Trail):**
    *   Toda vez que uma campanha for criada (`*criar-raspadinha`), o `@vendas` deve gerar um output estruturado para o `@financeiro` registrar o custo previsto.
    *   Deve existir uma task `notificar-campanha.md`.

3.  **Organização de Arquivos:**
    *   As tasks de vendas devem ter prefixo `vendas-` para não poluir a pasta raiz de tasks.
